# BlockDopaminContents

曜日・時間帯を指定してサイトへのアクセスをブロックする Firefox 拡張です。
外部サービスやアカウントは不要で、設定はブラウザー内に保存します。

## Firefox への読み込み

1. このリポジトリをダウンロードします。
2. Firefox で `about:debugging#/runtime/this-firefox` を開きます。
3. 「一時的なアドオンを読み込む」から `manifest.json` を選びます。
4. ツールバーの拡張ボタンから設定を開き、サイト・曜日・時間を登録します。

一時アドオンは Firefox の再起動で削除されます。通常の継続インストールには
Mozilla による署名が必要です。ストアへの公開や署名はこのリポジトリには含みません。

## スケジュール

- `youtube.com` はそのサイトとすべてのサブドメインが対象です。
- URL を入力した場合、パスやクエリーは無視してサイト全体を対象にします。
- 時刻は端末の現地時刻です。開始を含み、終了を含みません。
- `22:00〜06:00` は選択した曜日の22時から翌日6時までです。
- 開始と終了が同じなら、選択した曜日の終日をブロックします。
- 複数のスケジュールのいずれかに該当するとブロックします。
- 新規アクセスを遮断し、開いている対象タブも時間帯の開始時に切り替えます。
  スリープ中などの確認は復帰後に行われます。
- 終了後はサイトを再度開いてください。元のページへは自動で戻りません。
- 自己管理を支援する拡張です。設定変更や拡張の無効化による解除は防ぎません。

## 開発・検証

依存パッケージのインストールは不要です。Node.js 18 以降で `npm test` を実行します。
拡張を変更したら `about:debugging` の「再読み込み」を押してください。

Firefox での手動確認: 現在の曜日・時刻を含むスケジュールに `example.com` を追加し、
新規アクセスと既存タブの遮断を確認します。無効化すると再アクセスできること、
時刻の境界で既存タブが切り替わることも確認してください。

権限: 全サイトのリクエストを判定するための webRequest と webRequestBlocking、
開いているページを切り替える tabs、設定保存の storage、定期確認の alarms を使います。
閲覧履歴を外部に送信しません。プライベートウィンドウでは Firefox 側で別途許可が必要です。
